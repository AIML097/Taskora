# Summary
TASKORA is an AI-powered smart task management system designed to improve productivity by intelligently organizing and prioritizing tasks. The system integrates machine learning techniques to analyze user inputs, extract tasks from messages, and assign priority levels. TASKORA aims to assist users in efficiently managing their daily activities through automation and intelligent decision-making.

# Statement of Need
Traditional task management systems rely heavily on manual input and lack intelligent prioritization. Users often struggle to manage tasks efficiently due to the absence of automated analysis and prioritization mechanisms. TASKORA addresses this gap by introducing AI-driven task extraction and prioritization, enabling users to focus on high-priority tasks and improve overall productivity. This system is particularly useful for students and professionals handling multiple communication platforms.
